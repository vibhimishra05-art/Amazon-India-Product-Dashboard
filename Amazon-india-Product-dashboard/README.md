Amazon India Product Amazon India Sales Dashboard | Excel
Project Overview
This project presents an interactive Amazon India Product Sales Dashboard developed using Microsoft Excel. It provides insights into sales performance, profitability, order status, product performance and category-wise sales.
Dashboard Preview

Key Performance Indicators (KPIs)
	•	Net Sales: ₹14.01 Cr
	•	Net Profit: ₹3.32 Cr
	•	Total Orders: 10,000
	•	Profit Margin: 23.67%
	•	Revenue Loss: ₹1.56 Cr
Dashboard Features
	•	Order Status Distribution
	•	Category-wise Total Sales
	•	Net Profit Margin by Category
	•	Monthly Sales and Profit Trends
	•	Top 10 Products by Sales
	•	Interactive Category and Order Status Slicers
Tools & Techniques

	•	PivotTables

	•	Data Visualization

Key Objectives
	•	Analyse overall sales and profitability.
	•	Understand order status distribution.
	•	Compare sales across product categories.
	•	Identify top-performing products.
	•	Monitor monthly sales and profit trends.
